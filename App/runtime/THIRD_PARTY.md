# Private runtime input provenance

These files describe candidate build inputs, not an accepted installer. CPython3.13.16 x64 standard-GIL embeddable archive is pinned in interpreter.json to its official release-page SHA256. requirements-win-x64.lock pins the15 Windows/universal wheels; wheel-sources.json records their official PyPI download locations. Versions/hashes, filenames, target tags, Requires-Python, default dependency edges and wheel RECORD contents must be checked before assembly. No user-machine pip resolution is permitted.

Wheel redistribution notices are kept with their packages and recorded in the final manifest. This includes NumPy's bundled native-library notices and pyqtgraph's additional color-map license; a single top-level package label is not a substitute for those files. CPython's original license/native notices must also be retained. A license inventory is not a claim of publisher authentication or completed public-source licensing review.

pyserial3.5's wheel lacks the full LICENSE.txt, although its METADATA declares BSD and upstream source files carry SPDX notices. license-files.json binds the matching v3.5 upstream LICENSE.txt by URL/SHA256 to that exact package/version/wheel hash. Assembly must verify and copy this external input into licenses/pyserial-3.5.txt; missing or mismatched notice blocks the payload. Merely reporting a closed dependency graph does not satisfy this license gate.

Default PyMeasure dependencies include pandas, Pint and pyqtgraph. No Qt binding/application or test/tcp extras were requested. Upstream library helpers must not become a selectable instrument backend; application startup, pages and drivers remain real-only. Developer Matplotlib/Pillow and the development environment are not part of this runtime lock. Keep only qualified runtime assets; any exclusions of unused upstream tests/data need an explicit manifest rule and actual headless-import proof.

The assembler excludes wheel paths with a directory segment named tests, test, examples, benchmarks or __pycache__, plus .pyc/.pyo files. Declared license/notice paths are retained even under those directories. Each exclusion is recorded by wheel/original path/reason in runtime-manifest.json; installed RECORD files are regenerated from actual mapped retained bytes. The public numpy.testing support API is retained, not confused with a tests directory. Wheel purelib/platlib data is mapped explicitly; other data layouts and all vendor .pth/._pth files are rejected. No arbitrary post-install scripts run.

Payload application resources come only from regular blobs of an explicitly named Git commit, not working-tree wildcards. Uncommitted changes are left untouched and excluded. The manifest records this source identity, all retained file hashes, interpreter/locked wheel metadata, external notices and deterministic build identity. A temporary sibling is admitted only after its final on-disk inventory matches; failures never overwrite an existing destination. Git LF/CRLF text checkout changes are tolerated only when checking the four text input catalogs; packaged bytes still come from the named commit.

Offline archives/wheels and the external notice are staged outside source. On this development computer, candidate input commit a62eec4 was actually assembled: 3066 retained files, 1737 excluded upstream assets, 96676478 payload bytes excluding the manifest. The exact private executable passed28 worker/driver/setup module imports, target package-version checks, isolated search paths with external Python-environment poison, and an empty protocol3 ping/activate/status/shutdown (exit0). Local evidence is under Result/console/private-runtime-a62eec4-20261006 and is not published source. This is not native GUI/Host launch, vendor DLL availability on another machine, hardware control or clean Windows acceptance; those gates remain pending.
