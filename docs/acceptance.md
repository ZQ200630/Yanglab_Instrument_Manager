# Development checkpoint

This public repository contains development source, not a fully accepted standalone installer.

The drivers, native Host/GUI and offline test sources are included. Physical instrument acceptance, authenticated remote-host operation and a genuine Windows installation without Python/Anaconda are distinct pending work; no successful release is implied by source publication.

Private local measurement logs, operation receipts and detailed machine acceptance transcripts are intentionally omitted. Future acceptance evidence must distinguish software cleanup from physical output measurements.

Use docs/development.md and AGENTS.md when continuing development.
