# OSA Trace Driver Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans inline, task-by-task. Steps use checkbox syntax. The operator automatically approved equivalent planning/execution handoffs; do not wait for another reply.

**Goal:** Read an existing real AQ6370 trace without changing panel measurement state, preserving native samples, supported units and honest consistency metadata.

**Architecture:** Keep VISA ownership and cancellation in the existing AQ6370 driver. Add a small pure trace-data/decoder module and a bounded typed read path; explicitly track software-owned sweeps so ordinary connect/read/close never aborts panel measurements. Driver output is independent of the GUI/cache and will feed the subsequent archive/page increment.

**Tech Stack:** Existing Python/NumPy/PyVISA in Anaconda VISA; no new dependency.

**Spec:** `docs/superpowers/specs/2026-10-06-real-console-design.md`, OSA portion of sections 3 and 7.

## Global Constraints

- Python is `D:/SoftwareInstaller/Anaconda/envs/VISA/python.exe -B`; reusable drivers in Code/Utils, diagnostics/tests in Code/Debugs, generated evidence in Result/console.
- No instrument emulator, raw SCPI UI, front-panel setting setters, format changes, implicit sweep or read retries. reference_code and historical results stay read-only.
- Existing resource reservations, borrowed-manager lifetime, transaction/generation fences and bounded cleanup stay intact. Retained ownership is never reported released.
- Tonight permits disclosed identity/metadata/existing-trace reads and safe shutdown only; no new OSA sweep or nonzero outputs/motion.
- No main merge. Native UI acceptance remains pending; Gain probe/absent devices are not accepted by these tests.

## Review Focus

- A panel REPEAT measurement is running when the user only connects, reads or closes: no INIT or ABORt.
- A declared binary length is huge, truncated or indefinite: reject before unbounded allocation and never publish partial data.
- A density/math/contradictory level mode is selected: no unconditional dBm compatibility field.
- The panel changes count/unit/format/context during transfer: discard known inconsistency; unchanged context still does not prove atomicity.
- Close races a blocked read or sweep start: preserve resource ownership and prevent a late INIT after the close's abort.

## File structure and interfaces

- Create `Code/Utils/osa_trace.py`: immutable trace/context objects and pure bounded decoding; no resource or storage ownership.
- Modify `Code/Utils/osa.py`: read transaction, cancellation and owned-sweep lifecycle.
- Modify `Code/Debugs/check_osa.py`: mutually exclusive identity/read/sweep diagnostics and native evidence output.
- Create `Code/Debugs/test_osa_trace.py`; retain/update `test_osa_lifecycle.py`, `test_check_osa.py` and OSA cases in `test_drivers.py` without deleting safety cases.

`TraceContext` is frozen and contains `transfer_format: str`, `sample_count: int`, `spacing: int`, `level_unit: int`, `x_unit: int`, `trace_attribute: int`, `active_trace: str`, `center_m: float`, `span_m: float`, `resolution_m: float`, `sweep_mode: int`. Formats are ASCII, REAL,32 or REAL,64; count is 1..200001; spacing/x-unit are 0/1; level-unit 0..3; attributes 0..5; sweep modes 1..3. Reject malformed/non-finite context. Zero span is valid.

`TraceCapture` is frozen: immutable `wavelength_nm` and `native_values` float arrays, `native_unit: str`, `trace: str`, `identity: str`, UTC `read_started_at`/`read_finished_at`, `elapsed_s: float`, `context_before`/`context_after: TraceContext`, `consistency: str = "unproven"`. Never invent measurement time. Arrays must match count, be finite, and have positive strictly increasing wavelengths. `power_dbm` is a read-only compatibility property: native dBm unchanged; positive absolute W converted by 10*log10(W/0.001); otherwise unavailable, never fabricated.

For the initial validated transfer, admit ordinary optical-power trace attributes 0..4 and matching absolute units (spacing/unit 0/0 => dBm, 1/1 => W). Density units 2/3 and CALC attribute 5 are explicitly unsupported until their transfer interpretation is independently validated; reject before numeric data queries. Do not label TRACe:Y as density merely from the display unit. This is a capability boundary, not silent normalization.

`decode_trace_reply(reply: bytes, transfer_format: str, expected_count: int) -> np.ndarray` decodes strict ASCII or IEEE definite-length little-endian f32/f64, accepts only no suffix/LF/CRLF, requires exact expected length/count, and caps each 1024-point response at 65536 bytes.

`AQ6370.read_trace(trace: str = "A", timeout: float | None = None) -> TraceCapture` is the public existing-trace path; `_read_trace_locked(trace_name, deadline, generation) -> TraceCapture` is shared with legacy acquire while its transaction is already held. Traces normalize A..G/TR[A..G]. A whole-transfer monotonic deadline bounds each VISA call's local timeout; no global control-frame limit changes.
